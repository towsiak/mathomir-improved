Changes:
- Element allocation type and parent are thread-local. The eight-curve regression
  exposed heap corruption when UI editing and background graph calculation shared
  these temporary allocation settings; independent thread context fixes the race.
- Eight writing colors: black, red, green, blue, gray, orange, purple and teal.
  A Colors button sits beside the permanent Search tools. Colors apply to highlighted
  text without changing bold or font, selected objects, or the focused object.
  Search a color name to apply it. Highlighted text uses R red, G green, B blue,
  K black, H gray, A orange, P purple, T teal. Selection remains for changing colors
  again; Ctrl+B toggles bold separately, instead of B unexpectedly making bold.
- Function graphs now offer eight colored function slots; old graphs retain their
  existing four and gain empty extra slots when opened. Buttons fit the graph height.
- Resize grip sits on the actual lower-right object corner. Drag scale follows
  the corner diagonal and retains proportions, with no floating detached grip.
- Graph Smart fit keeps the horizontal window and fits finite function samples
  vertically, trimming extreme 5% tails per function and adding readable padding.
  Fits commit once after sampling, avoiding progressive scale jumps. Constant
  functions receive useful padding; invalid-only results keep the previous view.
- The graph toolbar has a labeled Fit button. Search Smart fit, Reset view,
  Zoom in gently or Zoom out gently. Reset uses -10..10, or -2pi..2pi in pi mode,
  or 0.1..100 on log axes, and fits the functions. These commands are undoable.

  Graph ranges are limited to +/-1e12, with minimum linear span 1e-9 (or relative

VERSIONED CRASH RECOVERY (v18)
Recovery runs automatically, independent of the old Never/Low/Medium/High setting.
Normally writes about one second after edits stop, or every five seconds during
continuous editing. Active move/resize/rotate gestures and running graph workers
must finish before a consistent snapshot is saved. Disk errors are retried.
Every successful snapshot has a timestamp and process ID; older versions stay.
Completed bytes are flushed before publishing a version, and Latest.mom is
replaced safely. A failed write leaves existing recovery files intact.
Files: %LOCALAPPDATA%\MathomirImproved\Recovery
Use the visible Search box: recover. Choose Latest.mom for recent edits or an
older Recovery-YYYYMMDD-HHMMSS-milliseconds-process.mom for an earlier version.
Recovery opens as a modified document so Save As lets you choose its new name.
Recovery files are retained; remove unwanted older versions from that folder.
Recent keystrokes before a snapshot can still be lost in a sudden crash.

V14 DRAWING ROTATION AND INTERVAL PRESETS
Point at an ordinary drawing, brace, arrow, shape or interval diagram and drag
its round rotation grip. Rotate button also enables that grip. Shift snaps to
15-degree increments. Escape cancels; Undo restores. Rotation always uses a
snapshot of the original geometry so repeated mouse events do not compound.
Nested ordinary drawings and text labels rotate together.
Special drawing objects (live graphs, bitmap images, drawing containers) are
not handled by this geometry rotation and do not show its grip.
Search 'number line' or 'interval' for four presets: (a,b), [a,b], (a,b], [a,b).
Choose one, then click in the document to place it. Open endpoints have hollow
circles; included endpoints have filled dots. The interval is a heavier line,
with thin number-line extensions and arrows. Labels a and b are editable text.
Move, resize, rotate, save and reopen these as ordinary drawing objects.

V15 TABLE AND PALETTE TOOLS
The brace/arrow drawing palette now includes a table-grid icon and four
interval icons. Table opens setup first: 1-20 rows, 1-12 columns (at least
two cells), 40-800% font size, alignment, and all/outer/header/no borders.
Choose Place table, then click in the document. Cells use the native table
editor for text and equations, and expand with their contents. Search 'table'
also opens setup. The four interval icons use the same templates as Search.
A second move grip is 22 screen pixels right and 12 pixels below the resize
corner. Both move grips take priority over ordinary object clicks.
Grips disappear when the pointer leaves the object/grip area or document view,
except during an active move, resize or rotate drag.
