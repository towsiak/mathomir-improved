Windows executable built with Visual Studio 2022 via GitHub Actions.
Interactive behavior has not been verified on Windows.

Changes:
- Double-click starts free placement even within expression bounds.
  Double-click and release for a new typing cursor; double-click and hold
  the second press, drag and pause for the existing quick-brace gesture.
  Single-click copy remains. Modifier clicks retain existing behavior.
- Frame activation uses standard MFC handling without forcing focus back
  to the main window. Internal modal dialogs do not trigger clipboard image
  generation/document mutation. Editor timer work pauses while the frame
  is disabled by a modal dialog.
- Active drawing tools take priority over expression selection, even when
  starting inside an exponent. Ctrl retains object selection in drawing mode.
  Normal click-to-copy remains available when no drawing tool is active.
- Full redraw on hover selection changes to preserve overlapping annotations.
- Recheck expression copy clicks at the actual cursor position.
- Drawing selection uses distance to visible line segments with a small
  screen-pixel margin. Ordinary node hover is capped at 2 pixels.
  Ctrl retains larger node handles.
- Printing creates object bitmaps only when image printing is enabled, fills
  only their bounds, and restores the selected bitmap before deleting it.
- Typing +- and -+ combines the operator in place while retaining the live
  empty cursor element, avoiding its deletion and reconstruction.
- Modern MSVC compatibility fixes for floating-point absolute values.
